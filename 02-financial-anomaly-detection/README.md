# 金融异常检测

DGraph-Fin 联系人图的欺诈用户识别实验。下载[四组实验发布包](金融异常检测-四组实验.zip)可获得课程原题、测试提交指南、完整代码、已训练模型、指标和复现说明。也可以直接查看[程序报告](程序报告.pdf)。

| 实验 | 已训练模型 | 原实验验证 ROC-AUC |
| --- | --- | ---: |
| 原始 MLP | 20 维属性 MLP | 0.71151 |
| 固定 50 个特征 | 线性模型、MLP | 0.79307、0.80306 |
| 固定 50 个特征，换模型 | 分箱 FM、CatBoost、LightGBM | 0.80646、0.81043、0.81241 |
| 丰富图特征与五模型组合 | 4 个 LightGBM 和 1 个 CatBoost | 0.84027 |

用发布权重重新推理时，五模型组合的验证 AUC 实测为 0.84025。原提交版本的 Mo 系统测试 AUC 为 0.858。

解压后进入 02-financial-anomaly-detection，按包内 README 从 Mo 取得原始数据，使用 evaluate.py 复算指标或生成 Mo 提交所需的逐节点预测缓存。
